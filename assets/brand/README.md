# Pullock brand assets

Slogan: **Pull the key. Lock the Device.**

The user supplied `source/Pullock Logo Varianten.dc.html` for the website, favicon and macOS app. The original is preserved byte for byte. Its SVG paths, proportions, colors and gradients are retained; no AI redraw is used. `tools/brand/export.py` extracts self-contained SVGs without the design-tool runtime or external font requests.

- `pullock-symbol-dark.svg`: light artwork for a dark surface, from variant 1a.
- `pullock-symbol-light.svg`: dark artwork for a light surface, from variant 1b.
- `pullock-app-dark.svg` / `pullock-app-light.svg`: original rounded app canvases from variants 1c/1d.
- Wordmark typography in the supplied design: Poppins; the spelling and slogan remain unchanged.

Generated icon sizes derive from these vectors. Website status indicators must still describe actual product availability; the slogan is brand copy, not a test result.
