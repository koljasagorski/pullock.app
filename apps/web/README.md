# Pullock website

Next.js App Router, TypeScript, Tailwind v4; static output for GitHub Pages.
Requires Node.js 22.22.3 or newer. Versions are pinned in `package-lock.json`.

```sh
npm ci
npx playwright install chromium webkit
npm run typecheck
npm run lint
npm run build
npm test
npm run preview
```

Preview: http://127.0.0.1:4173. The local server binds only to loopback. The single
client component is an explicitly labelled browser simulation. It has no USB,
screen-lock, storage, analytics or account access. All fonts/images are local.

For a project page, set both build and preview variables:

```sh
NEXT_PUBLIC_BASE_PATH=/pullock.app NEXT_PUBLIC_SITE_ORIGIN=https://koljasagorski.github.io npm run build
NEXT_PUBLIC_BASE_PATH=/pullock.app npm test
NEXT_PUBLIC_BASE_PATH=/pullock.app npm run preview
```

For the target custom domain, leave `NEXT_PUBLIC_BASE_PATH` empty and set
`NEXT_PUBLIC_SITE_ORIGIN=https://pullock.app`. Configure the domain in GitHub Pages
and DNS separately; a CNAME file is not domain verification.

`secure-export.mjs` hashes the fixed inline hydration scripts in each HTML file
and prepends a CSP meta tag. GitHub Pages does not offer arbitrary HTTP header
configuration; the meta policy makes no framing/header guarantee.

`node scripts/render-social.mjs` reproduces the social image using the supplied
SVG identity and local font. App/favicons are generated by `tools/brand` at the
repository root. Fonts: Poppins (SIL Open Font License); icons: Phosphor (MIT).
Their licenses are retained in the installed packages and `public/licenses`.
