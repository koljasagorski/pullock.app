# Pullock website

Product landing page for Mac users, calm monochrome hardware aesthetic derived
from the supplied Pullock logo. DESIGN_VARIANCE 4, MOTION_INTENSITY 2,
VISUAL_DENSITY 4. Next.js static RSC pages, Tailwind v4 and native CSS; the browser
simulation is the only client component. Poppins is self-hosted via Fontsource.

System light/dark themes share semantic CSS variables. Neutral grays, no extra
accent. Control radius 8px, content panels 20px. Only action feedback moves;
reduced motion removes transitions. Native details provide keyboard-accessible
FAQ disclosure. The product is visibly in development; no download, test result,
testimonial or screen-lock confirmation is fabricated.

The original logo source and reproducible app/favicon exports live in
`../../assets/brand`. `usb-detail.webp` is an AI-generated editorial illustration
of generic hardware, not a Pullock-branded product or compatibility certification.
It was generated with the built-in imagegen tool on 2026-09-29 and optimized to
WebP without altering its contents. The PNG master is in `assets/brand/images`.

Provider details come from the user-supplied https://patchletter.com/de/impressum.
No unrelated Patchletter product promises were copied.
