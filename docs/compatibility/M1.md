Die fehlende passive Kennung betrifft den **beobachteten Key in seiner aktuellen Konfiguration**. Daraus folgt keine Aussage über jede YubiKey-Serie. Für dieses Gerät muss vor persistentem Enrollment entweder ein zulässiger passiver Nachweis gefunden oder das Identitätsmodell ausdrücklich geändert werden. Die bereits geplanten Alternativen sind ein bewusst auf die aktuelle Attach-Session begrenzter Key-Modus oder eine separat bewertete aktive Herstellerabfrage; keine davon ist freigegeben oder implementiert.
